📊 DATABASE INTEGRATION
================================================================================

Table: ApprovalQueue
  ApprovalId       INT IDENTITY PRIMARY KEY
  RequestType      NVARCHAR(50)  -- "CARD" or "LOAN"
  RequestId        INT
  RequestedBy      NVARCHAR(450) -- Customer UserId
  Amount           DECIMAL(18,2) -- For loans
  Status           NVARCHAR(50)  -- "Pending", "Approved", "Rejected"
  Priority         NVARCHAR(50)  -- "Low", "Normal", "High"
  Description      NVARCHAR(MAX) -- Details
  RequestedAt      DATETIME
  ProcessedAt      DATETIME
  ProcessedBy      NVARCHAR(450) -- Admin UserId
  ApprovalNotes    NVARCHAR(MAX) -- Admin notes or rejection reason

Joins:
  ApprovalQueue → Users (RequestedBy = UserId)

🔄 WORKFLOW DIAGRAMS
================================================================================

CARD APPLICATION WORKFLOW:
  Customer Submits
       ↓
  CardApplicationService.SubmitCardApplicationAsync()
       ↓
  ApprovalQueue Record Created (Status = "Pending")
       ↓
  Admin Views /admin/approvals/cards
       ↓
  Admin Clicks "Review"
       ↓
  Modal Opens (Customer Info, Card Type, Delivery Method)
       ↓
  Admin Decision:
    ├─ Approve → Status = "Approved", ProcessedAt = NOW
    └─ Reject → Opens Rejection Modal → Requires Reason
       ↓
  Page Refreshes, Application Moves to Appropriate Tab

LOAN APPLICATION WORKFLOW:
  Customer Submits
       ↓
  CardApplicationService.SubmitLoanApplicationAsync()
       ↓
  ApprovalQueue Record Created (Status = "Pending", Amount = Requested)
       ↓
  Admin Views /admin/approvals/loans
       ↓
  Admin Clicks "Review"
       ↓
  Modal Opens (Customer Info, Loan Type, Amount, Term, Purpose)
       ↓
  Admin Decision:
    ├─ Approve → Status = "Approved", Amount = Approved Amount, ProcessedAt = NOW
    └─ Reject → Opens Rejection Modal → Requires Reason
       ↓
  Page Refreshes, Application Moves to Appropriate Tab

📞 SUPPORT & TROUBLESHOOTING
================================================================================

Issue: No pending applications showing
  → Check ApprovalQueue table for records
  → Verify RequestType is "CARD" or "LOAN"
  → Verify Status is "Pending"

Issue: Approved/Rejected tabs empty
  → Check if approvals were processed
  → Verify ProcessedAt timestamp is set
  → Check database for Status = "Approved" or "Rejected"

Issue: Rejection reason not showing
  → Check ApprovalNotes field in database
  → Verify rejection reason was entered
  → Check if notes are being extracted correctly

Issue: Loan amount not updating
  → Check if approved amount was entered
  → Verify Amount field is being updated
  → Check if default to requested amount is working
