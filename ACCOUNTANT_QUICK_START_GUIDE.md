## YOUR ROLE AT A GLANCE

You are the **financial record-keeper**. Your job is to:

1. ✅ **Record** all banking transactions as journal entries
2. ✅ **Post** entries to the general ledger  
3. ✅ **Validate** accuracy via trial balance
4. ✅ **Report** financial position via statements
5. ✅ **Coordinate** with other departments

---

## YOUR DAILY WORKFLOW (9 STEPS)

```
1. RECEIVE TRANSACTIONS
   ↓ Banking operations send you daily activity
   
2. CREATE JOURNAL ENTRIES
   ↓ Record each transaction with debit & credit
   
3. VERIFY BALANCING
   ↓ Total Debits = Total Credits? YES
   
4. POST TO GENERAL LEDGER
   ↓ Entry status changes from Draft to Posted
   
5. UPDATE GL BALANCES
   ↓ Account balances automatically updated
   
6. RUN TRIAL BALANCE
   ↓ Check if Debits = Credits (should match)
   
7. GENERATE FINANCIAL STATEMENTS
   ↓ Balance Sheet, Income Statement, Cash Flow
   
8. CREATE REPORTS
   ↓ Analysis for management and auditors
   
9. COORDINATE & CLOSE
   ↓ Month-end reconciliation and period close
```

## COMMON TRANSACTIONS

### Customer Deposit of $5,000

```
Journal Entry:
├─ Debit: Bank Account (1010)           $5,000
└─ Credit: Customer Deposits Liability (2100)  $5,000

Effect: Bank's cash increases, bank's liability increases
        (you're holding the customer's money)
```

### Loan Payment of $2,000 (Principal $1,500 + Interest $500)

```
Journal Entry:
├─ Debit: Bank Account (1010)           $2,000
├─ Credit: Loan Receivable (1030)               $1,500
└─ Credit: Interest Income (4100)               $500

Effect: Cash increases, loan balance decreases, 
        interest income recorded
```

### Monthly Interest Accrual (10 loans @ avg $833/month)

```
Journal Entry:
├─ Debit: Interest Receivable (1050)    $8,330
└─ Credit: Interest Income (4100)               $8,330

Effect: Record interest earned this month,
        even if not yet collected
```

### End-of-Month Depreciation ($5,000)

```
Journal Entry:
├─ Debit: Depreciation Expense (5200)   $5,000
└─ Credit: Accumulated Depreciation (1070)     $5,000

Effect: Record wear and tear on equipment
```

## IF TRIAL BALANCE DOESN'T BALANCE

1. **Check for unposted entries**
   - Maybe an entry is still in "Draft" status
   
2. **Verify entry balances**
   - Each entry: Total Debits = Total Credits?
   
3. **Look for posting errors**
   - Did someone post wrong amount?
   - Did someone post to wrong account?
   
4. **Review reversals**
   - Recent correcting entries?
   
5. **Create correction entry**
   - Post correction to GL
   - Re-run trial balance
   - Should balance now

## IF ACCOUNT DOESN'T RECONCILE

### Bank Account Doesn't Match GL

```
GL says: $1,000,000
Bank says: $995,000
Difference: $5,000

Possible Causes:
  1. Deposit in GL but not cleared in bank yet (timing)
  2. Check written but not yet cleared (timing)
  3. Bank error (rare)
  4. GL posting error (investigate)

Solution:
  Create reconciling entry to document difference
  Track differences until cleared
```

### Loan Balance Doesn't Match Contract

```
Contract says: $50,000 owed
GL says: $48,000 owed
Difference: $2,000

Possible Causes:
  1. Payment received but not posted to GL yet
  2. GL posting error
  3. Interest calculation mismatch

Solution:
  Contact Loan Officer
  Verify payment/transaction
  Create correction entry if needed
```

## IMPORTANT RULES

### ✅ DO:

- ✅ Always balance each entry (Debit = Credit)
- ✅ Always reference source documents
- ✅ Always post timely (don't let backlog build)
- ✅ Always verify before posting
- ✅ Always use reversals for corrections (never delete)
- ✅ Always reconcile accounts monthly
- ✅ Always document unusual transactions

## KEY ACCOUNTING CONCEPTS

**Debit & Credit:**
- **Debit** (left side) = Increases ASSETS & EXPENSES, Decreases LIABILITIES
- **Credit** (right side) = Increases LIABILITIES, INCOME & EQUITY, Decreases ASSETS

**Golden Rule:**
- Every entry affects TWO accounts
- Total Debits MUST equal Total Credits
- This is called "Double-Entry Bookkeeping"

**Trial Balance:**
- List of all GL accounts with their balances
- Total Debits MUST equal Total Credits
- If not balanced, there's an error to find

**Financial Statements:**
- Balance Sheet = What the bank owns vs. what it owes
- Income Statement = How much money the bank made/lost
- Cash Flow = Where cash came from and where it went
