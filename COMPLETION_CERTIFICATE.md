## 💻 Technical Details

### Technology Stack
- **Framework:** .NET 9.0 with Blazor
- **Language:** C# and Razor Components
- **Database:** SQL Server (BFASdatabase)
- **UI Framework:** Custom CSS with Grid/Flexbox
- **Architecture:** Component-Based + Service Layer

### Code Organization
```
Components/
├── Layout/
│   └── AdminLayout.razor (Complete sidebar navigation)
├── Pages/Admin/
│   ├── AdminDashboard.razor
│   ├── Banking/ (7 pages)
│   ├── Accounting/ (5 pages)
│   ├── Finance/ (7 pages)
│   ├── Approvals/ (6 pages)
│   ├── System/ (7+ pages)
│   └── Reports/ (4+ pages)

Models/
├── DatabaseModels.cs (Updated with UserRegistration)
├── AuthModels.cs
└── Domain models

Services/
├── AuthService.cs (6 roles support)
├── RoleBasedNavigationService.cs (50+ routes)
├── UserRegistrationService.cs
└── Business logic services

Data/
└── BFASDbContext.cs (EF Core context)
```
